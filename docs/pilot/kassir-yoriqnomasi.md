# Guzar Kassa — kassir yo'riqnomasi (pilot)

Bu yo'riqnoma pilot do'kondagi kassir uchun. Har bo'lim bitta vazifa haqida.

## 1. Ish kunini boshlash

1. Kompyuterni yoqing. Guzar Kassa o'zi ochiladi.
2. Ismingizni tanlang va PIN kodni kiriting.
3. **Smena ochish:** kassadagi naqd pulni sanang va "Smena ochish" oynasiga yozing.
4. Yuqoridagi belgilarni tekshiring:
   - **"SINOV — FISKAL EMAS"** — dastur sinov rejimida. Pilotda bu normal holat.
   - **Fiskal ogohlantirish** (sariq) — internet uzilgan. Savdo davom etadi, cheklar keyin yuboriladi.

## 2. Savdo

| Tugma               | Vazifa                                                 |
| ------------------- | ------------------------------------------------------ |
| **F2**              | Qidiruv: tovar nomi yoki SKU                           |
| skaner              | Shtrix-kodni o'qiting, tovar savatga tushadi           |
| **F3**              | Tez savdo: ro'yxatda yo'q tovar (nomi va narxi qo'lda) |
| **F4**              | Savat chegirmasi (ruxsat kerak bo'lishi mumkin)        |
| **F5** / **F6**     | Savatni kechiktirish / kechiktirilganlar               |
| **F7**              | Mijozni tanlash (nasiya va qarz uchun)                 |
| **F9** yoki **F12** | To'lov oynasi                                          |
| **Enter**           | Savdoni yakunlash                                      |
| **F1**              | Barcha tugmalar ro'yxati                               |

**To'lov:**

- **Naqd:** mijoz bergan summani kiriting. Qaytim avtomatik hisoblanadi.
- **Karta, UzQR va boshqalar:** "+ Naqdsiz to'lov qo'shish".
- **Aralash:** naqd va naqdsizni birga kiritish mumkin.
- **Nasiya:** avval mijozni tanlang (**F7**). Qolgan summa qarz bo'lib yoziladi. Mijozning qarz chegarasi oshsa, menejer tasdiqlashi kerak.

**Qoidalar oynasi:** "Bu tovar uchun naqd to'lov taqiqlangan" yoki "limit oshdi" chiqsa, ko'rsatilgan usulda to'lang (masalan kartada). Bu qonuniy qoida, uni chetlab o'tib bo'lmaydi.

## 3. Bekor qilish va qaytarish

- **Chekni bekor qilish:** faqat fiskallashmagan chek uchun. Fiskal chek ("FISKAL CHEK" yozuvi bor) faqat **qaytarish** orqali bekor bo'ladi.
- **Qaytarish:** cheklar ro'yxatidan chekni toping, qaytayotgan tovarlar va miqdorni belgilang. Pul qanday olingan bo'lsa, shunday qaytariladi.
- Muddati o'tgan tovar sotilganda ogohlantirish chiqadi. Savdo to'xtamaydi.

## 4. Smenani yopish

1. **F8** — "Kassa va smena".
2. Kassadagi naqd pulni sanang va kiriting.
3. Dastur kutilgan summani ko'rsatadi. Farq bo'lsa, sababini yozing.
4. Smena hisoboti chop etiladi. Uni imzolab menejerga bering.

## 5. Nimalarga e'tibor berish

- PIN kodingizni hech kimga aytmang. Boshqa kassir sizning nomingizdan ishlamasin.
- Printer chek chiqarmasa, savdo baribir saqlangan. Chekni qayta chop etish mumkin (**NUSXA** belgisi bilan).
- Muammo bo'lsa, "Nosozliklar kitobi"ga qarang yoki menejerga ayting. **Kompyuterni savdo o'rtasida o'chirmang.**
